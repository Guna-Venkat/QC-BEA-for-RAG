# Report support

`source_reports/` preserves byte-exact historical reports, glossary and reconstruction/provenance material. `previous_navigation/` preserves superseded generated guides for traceability; their old paths and assertions are not current instructions.

Use top-level IMPORTANT_NUMBERS.md and RESULTS_INDEX.md for numbers; ALGORITHM_DEFENSE_GUIDE.md/CODE_MAP.md for implementation explanations; SCIENTIFIC_STATUS.md and COHORT_MAP.md for claim boundaries. Do not let old prose override machine tables or fill missing historical evidence.
