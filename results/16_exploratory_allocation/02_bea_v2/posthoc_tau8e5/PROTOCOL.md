# BEA_V2 post-hoc engineering protocol

This is a post-hoc exploratory evaluation at a manually selected engineering operating point (tau_stop=8e-5) after the preregistered BEA_V2 calibration failed. It cannot be interpreted as confirmation or as evidence that the original calibration protocol succeeded.

Fixed tau=0.00008; no further search. Original 150 development queries, two budgets, four methods: 1,200 logical rows. Up to 300 missing BEA_V2 answers; historical controls reused read-only. Any genuinely missing control is restored canonically into this namespace only and accounted separately. Eighteen exploratory paired contrasts, 10,000 cluster resamples, seed 42, Holm adjustment across all 18. No expansion.
